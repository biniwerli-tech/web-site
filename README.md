# BSM Conseil Protection — site internet

Site vitrine statique (HTML, CSS, JavaScript sans dépendance) : gammes, catalogue filtrable, demande de devis par e-mail.

- `index.html` : la page
- `app.js` : catalogue, sélection et envoi du devis
- `images/` : photos produits

Mise en ligne : GitHub Pages (Settings › Pages › Deploy from a branch › `main` / root).
